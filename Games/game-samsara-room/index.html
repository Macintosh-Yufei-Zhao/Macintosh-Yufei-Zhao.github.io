Game Review - 锈湖系列之轮回的房间 Samsara Room

Posted on 2025-08-04 In Games

基础信息

  • 价格：steam免费（良心啊锈湖）。
  • 游戏类型：解谜；单人；轻度悬疑。
  • 开发商：Rusty Lake。
  • 发行时间：2020年4月29日。
  • 游玩时间：全流程通关约1.5小时。
  • 语言：支持简体中文。
  • 其他联系：为锈湖cube和rusty lake系列的前作，五周年重制版。

剧情简介

你是一个人。你是谁？你可以是很多东西。你喜欢这些东西吗？生命的轮回，重获新生……锈湖的游戏剧情不需要过多介绍，玩就完了！

游玩体验

总体打分：4.5分。

警告：游玩体验包含剧透，请谨慎浏览。

锈湖延续了一如既往的风格，简单到有点南蚌的室内场景布置，不多的操作选项，诡异的画风，忧愁、悬疑又带点催眠的游戏音乐，处处都打着“这是锈湖”的烙印。游戏翻译为“轮回的房间”，玩完cube escape seasons之后更喜欢这样的设计了，同样的房间通过祭坛转换不同的视角，各种视角搜集线索打开一层一层的故事真相，在各个不同的房间中来回穿梭以寻找线索，一切的一切都指向了那个充满玄妙的低语——“enlighten me”—— 最终的婴儿也确实算得上是enlighten了。不错的游戏，爽！

游玩攻略

一个不错的完整攻略是[图文攻略]Samsara Room（含隐藏剧情） - Samsara Room攻略 - TapTap Samsara Room论坛，我参考了一点这个里面评论区的隐藏剧情流程，也有重定向链接。锈湖的游戏还是自己玩比较爽，可惜隐藏关还是太过于难想了一点……毕竟要在其他游戏和各种微博里面找线索这谁顶得住啊（cube escape paradox说的就是你）
